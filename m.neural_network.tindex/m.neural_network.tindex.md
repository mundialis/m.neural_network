## DESCRIPTION

*m.neural_network.tindex* creates a tile index of the possible tiles for
the data preparation. It will be used with
*m.neural_network.preparedata_part1* and *m.neural_network.preparedata_part2*.

There are in general two modes: apply and training mode.<br>
Default is **apply mode**: tindex will be created with given *tile_size* and *tile_overlap* and it is taken care, that the tindex rather exceeds the AOI, to ensure a gap free classificatioin.<br>
For training mode the *-t*-flag must be used.
As for apply mode, the tindex is created based on *tile_size* and *tile_overlap*. In contrast to apply mode it is ensured, that only tiles fully within the AOI are selected (to ensure no-data-free image-label-pairs).
Additionally the given input data can be checked for null-cells with *-s*-flag (tiles including null-cells will be removed from tindex).
In the end the data are split into training, validation, and if given test set.<br>
Besides this default grid creation, a two-level-grid can be created in train mode.
This grid can be generated by giving the number of tiles per row and column for each independent group (*num_tiles_ind_group_row*, *num_tiles_ind_group_col*).
Here an additional attribute `block` is appended to the tindex, giving an index of the indepent group of tiles.
This two-level-grid is reasonable, if spatially independent test, validation and training data are needed.

The *suffix* option may be used to add a suffix to each output tile/file
in order to create unique tile IDs that can later be combined with
results from other runs.


## EXAMPLES

### Create tile index

```sh
# for apply mode:
m.neural_network.tindex aoi=aoi image_band=dop_red output_dir=/mnt/data/ tile_size=1024 tile_overlap=256

# for train mode: normal grid and skip null-cell check
m.neural_network.tindex aoi=aoi image_band=dop_red output_dir=/mnt/data/ -t -s

# for train mode: two-level-grid with 10 % test data (and default 20 % validation)
m.neural_network.tindex aoi=aoi image_band=dop_red output_dir=/mnt/data/ -t num_tiles_ind_group_row=4 num_tiles_ind_group_col=2 test_percentage=10
```
